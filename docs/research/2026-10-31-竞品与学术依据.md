## 1. 竞品全景

### 1.1 行为学口径（最接近的对手）

#### pawsona.xyz —— CPTI / FPTI

| 项 | 内容 |
|---|---|
| 狗（CPTI）4 维 | O/S **Sociality**（Outgoing ↔ Selective）· A/P **Exploration**（Adventurous ↔ Perceptive）· F/I **Cooperation**（Affiliative ↔ Independent）· R/V **Emotionality**（Relaxed ↔ Vulnerable） |
| 猫（FPTI）4 维 | G/S **Sociability**（Gregarious ↔ Solitary）· I/V **Curiosity**（Investigative ↔ Vigilant）· D/C **Willpower**（Dominant ↔ Compliant）· R/T **Sensitivity**（Reactive ↔ Temperate） |
| 题量 | 4 题速测 + 16 题完整测 |
| 类型 | 各 16 型（4 字母代码，如 OAFR 魅力探险家、GIDR 磁场挑逗者、SVCT 沉默观察者） |
| 附加 | 品种探索器（60+ 犬种 / 30+ 猫种）、兼容性格网格、训练建议、丰富化建议 |
| 商业 | 免费 + 广告；无账号、无订阅 |
| 自我定位 | 「science-informed personality framework」「Unlike generic pet quizzes, the CPTI measures… across four independent behavioural dimensions」「draws on decades of published research in comparative psychology and ethology」 |

**竞争判断**：
- ✅ 做对了：明确反 MBTI 直译；猫狗**各自独立**的四轴（承认了物种差异）；用**具体情境**而非抽象形容（meet a stranger on a walk / exploring a new space / reacting to a sudden noise）。
- ❌ 缺什么：**只有 4 维**；**未公开任何维度出处**（无引用、无论文、无原始条目）；**无复测 diff**；**无多宠行为级对照**（兼容性格是离散类型配对）；**无压力信号独立处理**（其训练建议已开始接近行为建议）。
- ⚠️ 这直接压缩了「用行为学维度」这条差异化路径的空间 —— 我们不能拿这个当卖点。

#### 十六型猫格（iOS，广州黑箱网络科技，2026-06-05 发布）

- 16 道题；4 组观察维度：**亲人 / 独立 · 探索 / 安稳 · 好动 / 悠闲 · 外放 / 内敛**。
- 输出：四字母猫格代码 + 四组行为倾向 + 猫格名称 + 相处建议。
- 自述：「这里没有『好猫/坏猫』的判断，也不是行为诊断」「更希望它像一次温柔的观察」——**合规姿态与我们一致**。
- 分享：Instagram / 微博 / 小红书 / X / 下载 PNG。
- 局限：仅 iOS；4 维；无出处。

#### Meow MBTI / 喵格测试（iOS，开发者「虎 李」）

- 16 道行为观察题；4 维：**M/S 社交力 · B/A 亲和力 · T/N 情绪力 · I/C 探索力**。
- 输出：16 种猫格 + 雷达图 + 典型日常行为 + 相处建议 + **最适配生活环境** + 常见品种参考 + **按年龄/健康/收养经历做「智能修正」** + **多猫档案与复测记录**。
- 8 种语言。
- 自述：「不构成兽医学或动物行为学诊断」「建议定期复测」。

**竞争判断**：**这是功能最完整的竞品**，尤其「智能修正」和「复测记录」已覆盖我们 v1.1/v1.2 的部分设想。
- 但「智能修正」未公开依据（学术上有依据：Turcsán 2009 显示年龄、绝育、获得年龄、训练经历都显著影响四Trait），我们可以用**有出处的修正**打差异化；
- 它的「复测」是并列展示历史记录，**不是逐维 diff**。

#### Pup Personality（iOS，Big Paw LLC，2026-05-25 发布）

- 20 题 / 16 原型 / 约 3 分钟；可保存**多只狗**的档案；90+ 犬种图标；14 种语言；完全离线。
- **铲屎官与狗狗 4 维契合度**、灵魂伙伴匹配、狗狗约玩配对、可定制分享卡、今日之星社区。
- 商业：免费 + $0.99 一次性买断（去广告 + 深色分享主题）；含联盟链接（玩具零食推荐）。
- 迭代节奏快（2026-05-25 → 06-08 共 8 版），已加 AI 助手 PupBot。

#### Dogality Test

- MBTI 派狗性格测试；自述「**not a scientifically validated assessment or a veterinary diagnosis**」；强调「问题关注你观察到的行为，而不是犬种」。
- 局限：4 维，无复测。

## 2. 学术依据

### 2.1 猫

**赫尔辛基大学 2021** — Mikkola S, Salonen M, Hakanen E, Sulkama S, Lohi H. *Reliability and Validity of Seven Feline Behavior and Personality Traits.* **Animals (Basel). 2021;7(11):1991.**

- 样本：**4300+ 只猫**，覆盖 **26 个品种组**；问卷 **138 条陈述**；做了**重测信度**（1–3 个月后同一主人或同户另一成人重填）与**评分者间信度**检验。
- 因子分析得到 **7 项**：
  1. Activity / playfulness（活动与玩耍）
  2. Fearfulness（恐惧性）
  3. Aggression towards humans（对人攻击性）
  4. Sociability towards humans（对人亲和）
  5. Sociability towards cats（对猫亲和）
  6. Litterbox issues（乱尿/乱便与猫砂盆洁净度）
  7. Excessive grooming（过度舔毛）
- **关键结论**：第 1–3 项是既往研究中最常复现的；**第 6、7 项不是人格特质，而是压力敏感度的指标**（→ 支柱三的依据）。
- 品种差异：**俄罗斯蓝猫**恐惧性最高、**阿比西尼亚猫**最低；**孟加拉豹猫**最活跃、**波斯猫 / 异国短毛猫**最被动；**暹罗猫 / 巴厘猫**过度舔毛最突出；**土耳其梵猫**对人攻击性显著更高且对猫亲和显著更低。
- 论文明确提醒：品种比较是「粗略印象」，未做两两比较（no pairwise comparisons）。

**Feline Five（2017）** — 约 3000 只家猫问卷，五因子：
Neuroticism（神经质）· Extraversion（外向性）· Dominance（支配性）· Impulsiveness（冲动性）· Agreeableness（宜人性）。
→ 用于 D15 冲动性、D9 社交主动性、D7 亲和的交叉校验。

**社会化窗口** — 芬兰 2020 年将幼猫断奶推荐年龄从 12 周提高到 **14 周**（依据 2017 年研究）；12 周前与陌生人接触少或不接触的猫恐惧性显著更高。恐惧可能先于攻击（嘶叫、咬）。

### 2.2 狗

**Turcsán / Kubinyi / Miklósi 2009** — *Dog and owner demographic characteristics and dog personality trait associations.* **Behavioural Processes 81(3):392–401.**

- 样本：**14004 只狗**（267 个品种 + 3920 只混种），德语区在线问卷。
- 四项特质：**calmness（沉稳度）· trainability（可训练性）· sociability（同种社交性）· boldness（大胆度）**。
- 关键效应（→ D12 变动耐受 / 纵向轨迹的科普依据）：
  - 2.5 岁以下最不稳沉，6.9 岁以上最稳沉
  - 4.8 岁以上最不同种社交；主人每日陪伴 <3 小时者社交性显著更低
  - 参加 3 种以上专业训练课程的狗可训练性最高
  - 12 周龄前获得、2 岁以下的公狗最大胆
  - 正式训练（服从/敏捷）显著提高沉稳度
- 结论原文强调：主人的陪伴时长与互动方式显著塑造狗的社交性 —— **主人是可干预变量，这是「相处建议」的正当性来源**。

**DPQ（Dog Personality Questionnaire，Jones 2008 简版；Turcsán 德译；Riemer et al. 2016, Applied Animal Behaviour Science 180:78–86 附表）**

- 5 因子 / 16 facet，5 点 Likert：
  1. **Fearfulness** — Fear of People / Nonsocial Fear / Fear of Dogs / Fear of Handling
  2. **Aggression towards People** — General / Situational（含**护物**）
  3. **Activity / Excitability** — Excitability / Playfulness / Active Engagement / Companionability
  4. **Responsiveness to Training** — Trainability / Controllability
  5. **Aggression towards Animals** — Aggression towards Dogs / Prey Drive / Dominance over Dogs
- **反向计分题**（附表中标 `*` 者）—— 反向题设计的直接先例。
- 信度：Cronbach's α 分别约 0.79 / 0.71 / 0.68 / 0.65 / 0.67。

**Volhard PAT**（Wendy & Jack Volhard，49 日龄，10 项，1–6 分）：Social attraction / Following / Restraint / Social dominance / Elevation / Retrieving / Touch sensitivity / Sound sensitivity / Sight sensitivity / Stability。
**Campbell's Puppy Test**（William Campbell, 1972）：前 5 项的来源。
**BreedTools 5 维**：Confidence / Social Drive / Trainability / Sensitivity / **Recovery**。
→ **「Stability 与 Recovery 分开测」是我们把 boldness 拆成 D1/D2/D3 的依据。**

**PAWS Working Dog Evaluation**：Possessiveness / Attention / Willingness / Strength，7 个测试区。

### 2.3 通用动物人格轴

**Carter et al. 2012**, *Biological Reviews* 88:465–475 —— 「动物人格到底在测什么」：跨物种稳定的轴主要是 **boldness、activity、aggression、sociability**，加上 **responsiveness to handling**。

**斑马雀（Barrett et al., Royal Society Open Science）** —— 41 只，两年追踪，测 **boldness、dominance、activity、risk-taking/aggression、persistence**：
- **只有 boldness 与 persistence 在两年内保持一致**，其余更易变。
- 问题解决成功与 **boldness、dominance、persistence** 相关。
→ ①「boldness 与 neophobia 部分独立」；②「同一只动物的特质会随时间变化，但有稳定核」——**纵向复测功能的双重依据**。

**家兔（Andersson et al. 2014, J. Ethology 32:1–14）** — *Two shades of boldness: novel object and anti-predator behavior reflect different personality dimensions in domestic rabbits* → boldness 可再分。

**主人-宠物人格相似性（Cavanaugh 等）** — 主人与狗在神经质、宜人性、开放性、外向性上呈相似趋势 → **纵向/横向比较的学理背景**；但跨物种量表直接相减**没有依据**（竞品的「主人×宠物契合度」正犯此错，我们不做）。

**犬猫分离相关行为、犬重复行为（过度舔咬）** → 压力信号轴的狗册指标来源。

### 2.4 产品结论（从证据到设计）

| 证据 | 设计决策 |
|---|---|
| 赫尔辛基明确 litterbox / excessive grooming **不是人格** | 压力信号**独立成轴**，不参与类型匹配（§6.2） |
| 斑马雀：boldness 与 persistence 两年稳定，其余易变 | 纵向轨迹只描述**变化**，不承诺稳定（§8.4）；也说明「性格会变」是正常的 |
| Volhard / BreedTools 把 Stability 与 Recovery 分开 | boldness 拆成 D1 / D2 / D3（§6.1） |
| 猫的经典画像 = 黏主人但怕生人 | 社交拆成 D7 / D8 / D9（§6.1） |
| DPQ 用 reverse-coded 中和赞许偏差 | 全卷约 1/6 反向题（§7） |
| Turcsán：主人的陪伴与训练显著塑造行为 | 「相处建议」有正当性，且**必须具体到动作**（§6.5） |
| 全部竞品分辨率都是 4 维 | 15 维 → 更细的分辨率，支撑多宠对照与复测 diff（§5 支柱四） |
| pawsona 已占「行为学口径」先手且无出处 | 竞争策略从「我们更科学」转为「**每一维可溯源 + 三种比较**」（§5） |
